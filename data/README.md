# Health Facility Locator Project

Overview
This is a simple Python-based tool designed to locate health facilities based on city input.
The project demonstrates basic scripting, data parsing, and automation skills that can support
internal project management and PMO workflows.

Purpose
The goal of this project is to showcase:
- Basic programming proficiency in Python
- Ability to parse structured data (CSV)
- Writing small internal tools to reduce manual work
- Clear documentation and maintainability

How It Works
- Loads health facility data from a CSV file
- Prompts the user to enter a city name
- Returns a list of health facilities in that city

Technologies Used
- Python
- CSV data handling
- Command-line interface (CLI)

How to Run
1. Clone the repository
2. Ensure Python 3 is installed
3. Run:
   python facility_locator.py
4. Enter a city name when prompted

Future Improvements
- Integrate external APIs for real-time data
- Add filtering by facility type
- Build a simple web interface
